# @canrush/site

Сайт canrush.ru — витрина цен на энергетические напитки по российским
ретейлерам и маркетплейсам. **Находится в стадии заготовки.**

## Источник данных

Сайт читает консолидированный срез цен, который готовит парсер:

```
../../data/latest.json
```

Формат описан в [`apps/parser/README.md`](../parser/README.md#структура-данных).
Товары из временно заблокированных источников помечены `stale: true` — на сайте
их стоит визуально отличать (например, плашкой «данные могут быть устаревшими»).

## План

- Карточка товара: название, бренд, объём (мл), цена, старая цена, изображение,
  ссылка на источник, бейдж `stale`.
- Сравнение цен по источникам для одного и того же товара (по `sourceId`/имени).
- Фильтры: бренд, объём, источник, диапазон цены.
- Обновление из `data/latest.json` без перезапуска (по расписанию или по
  запросу).

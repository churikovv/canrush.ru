# Парсер CanRush

Единственный источник цен — Едадил, HTTP API без браузера. Пятёрочка, Магнит, Лента и другие сети приходят через поле `retailer` в его предложениях. Цены акционные.

## Запуск из корня

```sh
npm install
npm run build
npm run parse -- --cities=all
npm run parse -- --cities=moscow,saint-petersburg
npm run parse -- --source=edadeal
npm run schedule
npm -w apps/parser run download-images
npm -w apps/parser run download-icons
```

`--force` обновляет региональные снимки до истечения срока кэша. Планировщик по умолчанию обходит все 16 городов ежедневно в 06:00 Europe/Moscow (`CRON_SCHEDULE`).

Конфигурация брендов, вкусов и Едадила: `config/products.json`. Снимки городов: `data/regions/<city>/latest.json`; каталог сайта: `apps/site/data/regions/<city>.json`. Кэш цен живёт 6 часов, повтор после ошибки — через 30 минут. Изображения и логотипы повторно используются из дискового кэша.

Сохраняются robots.txt, пауза 800 мс между запросами Едадила, последовательный обход городов и stale-фоллбэк. Сетевые ошибки не повод обходить ограничения источника. Уведомления об ошибках: `TG_BOT_TOKEN`, `TG_CHAT_ID` в локальном `.env`.

Браузерные адаптеры, партнёрские фиды и команды `doctor`/`session:unlock` удалены. Старые имена источников в общих типах оставлены для чтения исторических данных; запуск этих источников запрещён. Playwright используется только как инструмент проверки сайта при разработке.

Команды `ingredients` и `ingredients:publish` для обработки составов сохранены.

### Обновление составов

Составы собираются отдельно от цен, только с явным разделом «Состав». Запрос не публикует результат автоматически:

```sh
npm -w apps/parser run ingredients -- --query="Red Bull Sugarfree 250 мл состав" --limit=3 --budget=4
```

Кэш успешных карточек используется 30 дней, поисковых запросов — 7 дней. `--refresh` повторно проверяет источник, `--budget=0` отключает Tavily. Отчёты и исходный текст сохраняются в игнорируемой папке `data/ingredients/runs/`.

После проверки названия, конкретной версии, объёма и текста обновите `config/ingredient-products.json`: актуальный ключ бренда/вкуса из каталога, `reportId`, URL и SHA-256 точного текста состава. Original, Sugarfree и вкусовые версии — отдельные привязки. `unknown` и `unresolved:` публиковать нельзя. При недоступности источника сохранённая запись сохраняет прежнюю дату получения; неполный перечень требует `status: unverified` и пояснения.

```sh
# Для текущего volume сайта
npm -w apps/parser run ingredients:publish
# Для доставки через Git и следующую сборку сайта
npm -w apps/parser run ingredients:publish -- --bundled
```

Публикация проверяет привязки по каталогам всех городов, уникальность пары бренд/вкус и соответствие текста выбранному отчёту. При ошибке предыдущий файл остаётся целым. В Git добавляются конфигурация привязок и `apps/site/src/content/ingredients.json`, но не сырые отчёты. На VPS не нужно повторять сбор: достаточно обновить Git и пересобрать `site`. Если в volume уже есть `data/ingredients.json`, он имеет приоритет над встроенным срезом.

### Исправление идентичности напитков в сохранённых данных

После обновления правил вкусов выполните сборку и `node apps/parser/dist/index.js reindex-catalog` из корня репозитория. Команда пересобирает региональные и основной каталоги из сохранённых названий, без запросов к магазинам и повторного скачивания изображений. Запускайте её между прогонами парсера.

Смеси вкусов и версии без сахара имеют отдельные ключи. Нераспознанные предложения получают стабильный `unresolved:`-ключ по источнику, ID и названию вместо общей группы `unknown`. Сайт не принимает оценки таких предложений. Старые отзывы `unknown` сохраняются в прежней карточке без автоматического переноса на предполагаемый вкус. Обложка распознанного напитка берётся из общего каталога идентичностей и не меняется при выборе города.

Бренды `Volt`/`Volt Energy`, `Flesh`/`Flash Up` и варианты `Adrenaline` приводятся к `Volt Energy`, `Flash Up`, `Adrenaline Rush`. Явный бренд в названии предложения имеет приоритет над ошибочным полем магазина. Именованные линейки распознаются в `src/product-lines.ts`: например, Game Fuel остаётся самостоятельной карточкой внутри Adrenaline Rush, даже если магазин не указал вкус. Неизвестные линейки и предложения «в ассортименте» не приравниваются к оригиналу.

# История цен каталога

График читает региональные снимки парсера за последние 90 дней, строит отдельную линию каждой сети для выбранного объёма. Если у сети несколько предложений одного объёма за день, выбирается минимальное. Stale-предложения, неверные цены и акции, истёкшие до даты снимка, исключаются. Алиасы вкусов объединяются существующей нормализацией каталога. Дни без наблюдений не создаются.

Локально используются `data/regions/<city>/history/*.json`. На сервере Compose подключает существующий `parser-data` только для чтения в `/app/price-history`, а `PRICE_HISTORY_DIR=/app/price-history/regions` задаёт путь. После обновления пересоздать контейнер site, чтобы применился mount. Миграция БД для графика не нужна. При отсутствии истории показано пустое состояние; для одного дня показана одна точка. Кэш на 5 минут ограничен 100 комбинациями город/товар.

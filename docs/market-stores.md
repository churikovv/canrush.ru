# Магазины в маркете

`/market/stores`: публичные магазины, поиск, город, список / карта. `/market/stores?mine=1`: собственные заявки. `/admin/stores`: модерация.

Пользователь задаёт название, адрес, город и координаты входа вручную или кликом на карту. Метро необязательно. Прайс необязателен, максимум 50 позиций: название, цена в рублях (в БД копейки), наличие / нет / неизвестно. Это сведения участника с датой обновления, не автоматическая гарантия остатков.

Все заявки и правки требуют модерации. На время повторной проверки старая публикация скрывается. Только автор редактирует, только администратор публикует. Блокировка автора скрывает его магазины. Есть лимит ожидающих заявок, минутный интервал и защита от одинаковых названия/адреса. Модерация проверяет версию заявки, чтобы не одобрить незаметно изменённые данные.

## Карта

Runtime-переменная `YANDEX_MAPS_API_KEY` в `apps/site/.env.local` локально и в корневом `.env` на сервере. Compose передаёт её сайту. Значение не коммитить. Это браузерный API-ключ, он виден посетителю: ограничьте его доменами canrush.ru и localhost в кабинете Яндекса. Карта загружается только при выборе вида «На карте» или заполнении формы. Без ключа список и внешние ссылки работают, координаты можно ввести вручную.

Координаты ставит участник; геокодер и поиск организаций Яндекса не используются, результаты этих API не сохраняются. Не скрывать атрибуцию и элементы Яндекс Карт.

## Метро

Снимок публичного справочника `https://api.hh.ru/metro`, получен 2026-10-12, находится в `apps/site/src/lib/stores/metro.json`. Семь городов: Москва, Санкт-Петербург, Екатеринбург, Казань, Нижний Новгород, Новосибирск, Самара. Сохранены названия и линии, без координат. Москва включает МЦК, не включает МЦД и устаревшую Каховскую линию. Поиск в селекторе по станции/линии. При смене города выбор очищается; сервер проверяет соответствие станции городу. Справочник не обновляется в рантайме: перед очередным обновлением проверить изменения по данным операторов метро.

## Деплой

Фотографии необязательны: до 5 JPG/PNG/WebP по 5 МБ. Сервер проверяет и перекодирует изображения в WebP, хранит оригинал и миниатюру в БД. До публикации доступ есть только у автора и администратора; удалённые фото больше не раздаются. Изменения фото проходят повторную модерацию.

Сначала `db:plan`, затем миграции `0036_market_stores.sql` и `0037_store_photos.sql`, затем запуск нового сайта. Новая схема не меняет существующие данные.
